[Ziex](https://ziex.dev/) is a full-stack web framework for [Zig](https://ziglang.org/) that enables developers to build both backend applications and interactive client-side experiences entirely in Zig.

Beyond the framework itself, Ziex puts a strong emphasis on developer experience and tooling. It comes with a comprehensive ecosystem, including editor extensions, a Chrome DevTools extension, a language server, and the essential tools needed for a productive web development workflow.

The goal is to make building modern, interactive web applications with Zig a seamless and enjoyable experience.
