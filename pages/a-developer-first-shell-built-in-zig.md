## Description

[Wolysh](https://github.com/dev-dami/wolysh) is a fast, developer-aware shell built in Zig for modern development workflows, rather than trying to be another Bash or Fish replacement. This talk covers its design, current architecture, focus on speed and safety, and the next set of features I’m working toward shipping

## Bio

[Damilare Osibanjo](https://www.linkedin.com/in/damilare-osibanjo/) is a software and systems programmer focused on backend systems, developer tooling, and low-level software. He works primarily with Zig, Rust, Go, and TypeScript, and enjoys building compilers, runtimes, infrastructure, and developer tools. He is the creator of Wolysh, a Linux shell written in Zig focused on readable scripting, native job control, and safer command execution.
